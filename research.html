Method

How we think about the interface

Good UX research starts with the decision a person is trying to make — not with the number of interface elements we can fit on a screen.

Observe

Look at existing movie products, their interaction patterns and the assumptions built into their interfaces.

Frame

Turn observations into specific UX questions around discovery, comprehension and decision-making.

Prototype

Explore alternative information hierarchies and interaction patterns before committing to a visual system.

Refine

Keep the useful complexity and remove the friction that does not contribute to the user's goal.

Principles

A few rules we keep coming back to

01

Clarity before completeness

Showing everything is not the same as helping someone understand something.

02

Support the decision

A discovery interface should make the next useful action obvious without forcing a user through unnecessary steps.

03

Progressive disclosure

Keep deeper information available, but let the interface reveal complexity as interest increases.

04

Context matters

The same movie information can have very different value depending on where and when it appears.

05

Less noise, more signal

Every visible element should earn its place in the hierarchy.
