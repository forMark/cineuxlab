# CineUX Lab

UX research project exploring better digital experiences for movie blogs and entertainment platforms.

🌐 Website: https://formark.github.io/cineuxlab/

---

## About

CineUX Lab is an independent UX research project focused on how people discover films, read reviews and interact with cinema content.

The project explores interface patterns, content structures and user experience principles for digital movie products.

---

## Research areas

### Film discovery

Exploring how users search, browse and choose movies through:

- navigation systems
- categories and collections
- recommendations
- search experiences

### Movie interfaces

Studying effective ways to organize:

- posters
- ratings
- reviews
- metadata
- trailers
- related content

### Mobile experience

Researching comfortable movie browsing patterns for smartphones and small screens.

## Design principles

CineUX Lab focuses on:

- clarity over complexity
- meaningful information hierarchy
- reducing user friction
- helping people discover stories
